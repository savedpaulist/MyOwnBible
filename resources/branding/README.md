# MOB logo pack

Cross-platform application icon for BibleOWN / MOB.

## Files

- `mob-logo-master-1024.png` — 1024×1024 master PNG.
- `windows/mob.ico` — Windows icon containing 16, 24, 32, 48, 64, 128, and 256 px images.
- `windows/png/` — individual Windows PNG sizes.
- `macos/mob.icns` — macOS icon containing 16 through 1024 px representations.
- `macos/MOB.iconset/` — source PNG set compatible with Apple icon tooling.

The artwork uses a deep emerald background, warm ivory lettering and pages, and coral-orange accents. Keep the master artwork square; Windows and macOS apply their own display masks where appropriate.

## Generation prompt

Create a square, minimal vector-like application icon. Place the large capital letters “MOB” across the background. Put a clearly recognizable open Bible in the foreground, with a writing pen diagonally over the right-hand page. Use a deep emerald-green background and outlines, warm creamy off-white letters and pages, and vivid coral-orange book and pen accents. Preserve a strong silhouette, generous safe margins, and readability from 16×16 through 1024×1024. No extra text, no cross symbol, no tiny page text, no watermark.
